====================================
FIRESTORE SECURITY RULES - ADICIONAR AO FIREBASE CONSOLE
====================================

👇 Adicione este bloco às suas Firestore Security Rules (no Firebase Console):

====================================

// ===== Posts/Notícias do Carousel =====
match /noticias/{noticiaId} {
  allow read: if true; // Public read for carousel posts
  allow create, update, delete: if isAdmin();
}

====================================

📍 COMO ADICIONAR:
1. Acesse: https://console.firebase.google.com
2. Vá para: Firestore Database > Rules
3. Localize a linha: "match /databases/{database}/documents {"
4. Antes do fechamento "}" final, adicione o bloco acima
5. Clique em "Publish"

====================================

❌ SE NÃO ADICIONAR:
- Erro: "Missing or insufficient permissions"
- Usuário não conseguirá carregar/salvar posts

✅ APÓS ADICIONAR:
- Painel de admin funcionará perfeitamente
- Todos conseguirão VER os posts (public read)
- Só admins conseguirão EDITAR/DELETAR

====================================

EXEMPLO COMPLETO (após adicionar):

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function isAdmin() {
      return request.auth != null &&
        get(/databases/$(database)/documents/usuarios/$(request.auth.uid)).data.perfil == "admin";
    }

    // ... outras regras ...

    match /noticias/{noticiaId} {
      allow read: if true;
      allow create, update, delete: if isAdmin();
    }
  }
}
