🎯 O QUE FOI FEITO
==================

1. ✅ Interface atualizada (index.html)
   - Botão "📤 Enviar PDF" para upload real de arquivo

   - Para Aluno e Professor

2. ✅ JavaScript atualizado (index.html)

   - Converte para base64

3. ✅ Cloud Function criada (firebase-functions-upload.js)
   - Recebe arquivo em base64
   - Usa Google Drive API
   - Faz upload para pasta específica
   - Compartilha automaticamente
   - Retorna link para salvar no Firestore


🚀 PASSOS PARA IMPLEMENTAR
==========================

PASSO 1: ATIVAR GOOGLE DRIVE API
--------------------------------

1. Acesse: https://console.cloud.google.com
2. Selecione seu projeto Firebase
3. Vá para: APIs e Serviços > Biblioteca
4. Procure por "Google Drive API"
5. Clique em "Ativar"


PASSO 2: CRIAR CONTA DE SERVIÇO
-------------------------------

1. No Google Cloud Console:
   Vá para: APIs e Serviços > Credenciais

2. Clique em "Criar Credenciais" > "Conta de Serviço"

3. Preencha:
   - Nome: "adpf-revista-uploader"
   - ID: será gerado automaticamente
   - Clique "Continuar"

4. Clique em "Concluir"

5. Clique na conta que foi criada

6. Vá para a aba "Chaves"

7. Clique em "Adicionar Chave" > "Nova Chave" > "JSON"

8. **Salve o arquivo JSON com segurança!**
   (Ele tem as credenciais da conta de serviço)


PASSO 3: COMPARTILHAR PASTA NO GOOGLE DRIVE
--------------------------------------------

1. Abra seu Google Drive pessoal

2. Crie uma pasta chamada: "ADB Floripa - Revistas EBD"
   (Ou use uma pasta existente)

3. Dentro dela, crie 5 subpastas:
   - Cordeirinhos de Cristo (Jardim)
   - Estrela da Manhã (Juniores)
   - Adolescentes (Juvenis)
   - Renascer em Cristo (Jovens)
   - Colunas da Verdade / Sacerdotes de Cristo (Adultos)

4. Clique em "Compartilhar"

5. Copie o email da conta de serviço:
   (Do arquivo JSON que você salvou na Passo 2)
   - Procure por: "client_email"
   - Exemplo: adpf-revista-uploader@seu-projeto.iam.gserviceaccount.com

6. Cole o email e compartilhe com "Editor"


PASSO 4: ADICIONAR CLOUD FUNCTION AO FIREBASE
---------------------------------------------

1. Acesse: https://console.firebase.google.com

2. Selecione seu projeto "ADPF"

3. Vá para: Build > Functions

4. Clique em "Criar Função"

5. Configure:
   - Nome: uploadRevistaToGoogleDrive
   - Região: southamerica-east1 (ou sua preferência)
   - Disparador: Cloud Firestore / HTTP

6. Cole o código do arquivo "firebase-functions-upload.js"

7. Clique em "Deploy"


PASSO 5: ADICIONAR A CHAVE AO FIREBASE
--------------------------------------

A chave JSON que você criou na Passo 2 precisa estar disponível na Cloud Function.

OPÇÃO A (Recomendado - Secret Manager):
1. No Firebase Console:
   Vá para: Build > Functions > Variáveis de Ambiente
2. Clique em "Nova Variável"
3. Nome: GOOGLE_SERVICE_ACCOUNT_KEY
4. Valor: (Cole todo o conteúdo do arquivo JSON)
5. Salva
6. No código da Cloud Function, leia com:
   const serviceAccount = JSON.parse(process.env.GOOGLE_SERVICE_ACCOUNT_KEY);

OPÇÃO B (Mais simples - inserir no código):
1. Abra o arquivo "firebase-functions-upload.js"
2. Procure por: const GOOGLE_DRIVE_FOLDER_ID
3. Substitua com o ID da sua pasta:
   (Pegue da URL do Google Drive)
   Exemplo: https://drive.google.com/drive/folders/1ABC123XYZ
   ID: 1ABC123XYZ

4. Adicione as credenciais:
   const serviceAccountKey = require('./service-account-key.json');


PASSO 6: TESTAR O UPLOAD
------------------------

1. Acesse: http://localhost:8000

2. Vá para: ADMINISTRAÇÃO > Posts do Site > Gerenciar Lições

3. Selecione uma Sala

4. Em "Revista em PDF (Aluno)":
   - Clique em "Escolher Arquivo"
   - Selecione um PDF do seu computador
   - Clique em "📤 Enviar PDF"

5. Aguarde... (levará alguns segundos)

6. Se tudo der certo:
   ✅ Mensagem: "PDF enviado com sucesso!"
   ✅ Link aparecerá no campo
   ✅ PDF estará no seu Google Drive


PASSO 7: VERIFICAR NO GOOGLE DRIVE
----------------------------------

1. Abra seu Google Drive

2. Vá para: ADB Floripa - Revistas EBD > [Sala]

3. Você deve ver os PDFs que foi enviando!

4. Links compartilhados publicamente

===============

"Erro: Permissão negada"
→ Verifique se a pasta foi compartilhada com a conta de serviço

"Erro: Arquivo não encontrado"
→ Verifique se o usuário logado é ADMIN

"Erro: Cloud Function não existe"
→ Deploy da função não funcionou
→ Tente novamente no Firebase Console
