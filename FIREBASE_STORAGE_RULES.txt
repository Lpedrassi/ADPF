====================================================
FIREBASE STORAGE SECURITY RULES
====================================================

📋 ADICIONE ESTAS REGRAS AO FIREBASE CONSOLE

1. Acesse: https://console.firebase.google.com/project/adpf-7df40/storage/rules

2. Substitua TODAS as regras por:

====================================================

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    // Regra geral: negar tudo por padrão
    match /{allPaths=**} {
      allow read: if true; // Qualquer um pode ler os PDFs
      allow write: if false; // Ninguém por padrão
    }

    // Pasta de revistas: apenas admins podem fazer upload
    match /revistas/{salaId}/{ano_trimestre}/{fileName} {
      allow read: if true; // Qualquer um pode ler
      allow write: if request.auth != null &&
                      get(/databases/(default)/documents/usuarios/$(request.auth.uid)).data.perfil == 'admin';
      allow delete: if request.auth != null &&
                       get(/databases/(default)/documents/usuarios/$(request.auth.uid)).data.perfil == 'admin';
    }
  }
}

====================================================

✅ PASSOS:
1. Copie o código acima
2. Vá em: Firebase Console > Storage > Rules
3. Delete as regras antigas
4. Cole as novas regras
5. Clique em "Publicar"

⚠️ AGUARDE 1-2 MINUTOS para as regras serem atualizadas

====================================================

O QUE ESSAS REGRAS FAZEM:

✅ Qualquer um CONSEGUE LER os PDFs (alunos, professores, público)
✅ Apenas ADMIN consegue fazer UPLOAD
✅ Apenas ADMIN consegue DELETAR
❌ Usuários normais NÃO conseguem fazer upload
